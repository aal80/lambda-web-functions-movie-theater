AWS Lambda Web Functions Movie Theater

AWS Lambda Web Functions run ordinary Node.js web servers on Lambda. This movie theater is a plain Express.js app to show off Lambda Web Function response streaming. Every movie is a sequence of ASCII frames that the server sends one over a long-lived HTTP response. Check out the movies in your desktop browser or even your favorite console terminal.
